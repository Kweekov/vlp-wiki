# Совместные счета

Любую свою карту можно сделать совместной, добавив в неё других игроков с индивидуальными правами доступа.

## Добавить участника

<video src="assets/joint-adduser.webm" autoplay loop muted playsinline></video>

```
/vlb member add <код-карты> <ник> [member|viewer]
```

- `member` (по умолчанию) — полноценный участник: может пополнять, снимать и переводить с карты;
- `viewer` — только просмотр, без операций.

Пример:

```
/vlb member add VLB-001000 Steve member
```

## Настроить права участника

```
/vlb member set <код-карты> <ник> <право> <on|off|число>
```

Доступные права:

| Право | Что даёт |
|---|---|
| `deposit` | пополнять счёт (`on`/`off`) |
| `withdraw` | снимать со счёта (`on`/`off`) |
| `transfer` | переводить со счёта другим игрокам (`on`/`off`) |
| `manage` | управлять счётом (зарезервировано; управлять участниками может только владелец, см. ниже) |
| `wdlimit` | дневной лимит снятия в АРах (число; `-1` — без ограничений) |
| `trlimit` | дневной лимит переводов в АРах (число; `-1` — без ограничений) |

Примеры:

```
/vlb member set VLB-001000 Steve withdraw on
/vlb member set VLB-001000 Steve wdlimit 5000
/vlb member set VLB-001000 Steve trlimit -1
```

## Убрать участника

```
/vlb member remove <код-карты> <ник>
```

## Список участников и права

```
/vlb member list <код-карты>
```
(эквивалент `/vlb card info <код-карты>` — покажет владельца, баланс и всех участников с их правами в компактном виде: `+клад -снят +пер -упр`.)

## Ограничения

- Добавлять, убирать участников и менять их права может **только владелец** счёта — даже если у участника включено право `manage`, доступ к управлению участниками имеет исключительно владелец.
- Владельца счёта нельзя добавить в участники — он уже полноправный владелец.
- Дневные лимиты (`wdlimit`, `trlimit`) сбрасываются каждые сутки и действуют персонально для каждого участника.
- Замороженный (`frozen`) совместный счёт временно недоступен для операций всем, включая владельца, до разморозки администрацией.
