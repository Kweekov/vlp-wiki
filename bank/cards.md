# Управление картами

Все операции с картами — через `/vlb card <действие>`.

```
/vlb card create|list|select|rename|delete|info
```

## Создать карту

```
/vlb card create [название]
```

Название необязательно (до 48 символов). Карте присваивается уникальный код вида `VLB-001000`. Количество карт на игрока может быть ограничено настройками сервера — при достижении лимита сервер сообщит об этом.

## Список карт

```
/vlb card list
```

То же самое, что `/vlb balance` — список всех доступных вам счетов с кодами, балансами и отметкой активного счёта.

## Сделать карту активной

```
/vlb card select VLB-001000
```

Любую свою карту (или совместную, если вы в ней участник) можно сделать активной. Именно на активную **свою** карту будут приходить входящие АРы — подробнее в статье [Счета и карты](wiki:bank/accounts).

## Переименовать карту

```
/vlb card rename VLB-001000 Новое название
```

Переименовать может только владелец карты.

## Информация о карте

```
/vlb card info VLB-001000
```

Покажет название, владельца, баланс и список участников с правами доступа (для совместных карт).

## Удалить карту

```
/vlb card delete VLB-001000
```

Удалить может только владелец. Что происходит с деньгами:

- **Обычная карта** — если на ней есть баланс, сервер может потребовать сначала опустошить её (зависит от настроек). Если удаление непустых карт разрешено — баланс просто теряется вместе со счётом, будьте внимательны.
- **Личный счёт** — теперь тоже можно удалить. Для этого у вас должна быть хотя бы одна другая карта: она автоматически станет новым личным счётом, весь остаток с удаляемого личного счёта переносится на неё, и она же становится активной. Если других карт нет — удалить личный счёт нельзя (не бывает игрока совсем без счёта).

Удаление крупной операции может потребовать подтверждения:

```
/vlb confirm
```

(сервер присылает запрос на подтверждение, если удаление карт настроено как «опасное» действие).
