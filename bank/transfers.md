# Переводы

## Перевод другому игроку

<video src="assets/bank-transfer.webm" autoplay loop muted playsinline></video>

```
/vlb pay [код-счёта] <ник> <кол-во> [комментарий]
```

- `код-счёта` — необязателен, по умолчанию берётся ваш активный счёт;
- `ник` — получатель;
- `кол-во` — сумма в АРах (целое число);
- `комментарий` — необязательный текст, до 200 символов.

Пример:

```
/vlb pay VLB-001000 Steve 500 за дрова
```

Деньги списываются с указанного (или активного) счёта. Если получатель офлайн — уведомление о переводе придёт ему при следующем входе.

### Куда приходят деньги получателю

Перевод зачисляется на **активную собственную** карту получателя. Если у получателя сейчас активен чужой совместный счёт — деньги вместо этого уходят на его личный счёт. Подробнее: [Счета и карты](wiki:bank/accounts).

### Комиссия

Сервер может взимать комиссию с перевода (фиксированную и/или процентную) — она списывается сверх указанной суммы. Итоговая сумма получателю не меняется, комиссию платит отправитель.

### Лимиты и подтверждение крупных переводов

- Владелец совместного счёта может задать участникам дневной лимит на переводы (`/vlb member set ... trlimit <число>`) — подробнее в статье [Совместные счета](wiki:bank/joint).
- Если сумма перевода превышает порог, настроенный на сервере, потребуется подтверждение:

```
/vlb pay VLB-001000 Steve 100000
> Требуется подтверждение. Введите /vlb confirm в течение отведённого времени.
/vlb confirm
```

Без подтверждения такой перевод не выполнится.

## Перевод между своими счетами

Чтобы переложить АРы между своими же счетами (например, с личного на карту), используется отдельная команда:

```
/vlb move <код-источник> <код-получатель> <кол-во> [комментарий]
```

Пример:

```
/vlb move VLB-001000 VLB-002000 1000 на подарок
```

Для `move` нужны права на снятие с исходного счёта и на пополнение целевого (актуально для совместных счетов).

## Пополнение и снятие наличных

```
/vlb put [код] [кол-во]     — положить АРы из инвентаря на счёт
/vlb withdraw [код] <кол-во> — снять АРы со счёта в инвентарь
```

Если код счёта не указан — используется активный счёт.

## История операций

```
/vlb history [код] [страница]
```

Показывает подробный журнал: кто, когда, что сделал и какой стал остаток.
