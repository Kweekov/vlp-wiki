# VLP Wiki — контент

Контент вики VLP (GitBook-стиль) в Markdown. Отображается в игровом меню **F2** и на сайте.

## Структура

- `manifest.json` — дерево вики: категории → статьи (порядок = порядок в меню и навигация «пред/след»).
- `<категория>/<slug>.md` — статьи (Markdown).
- `assets/` — медиа (короткие немые `webm`, скриншоты `png`).

## Как это работает

Репозиторий — **источник контента**. Хосты (РФ-релей + Финляндия) периодически подтягивают его и раздают как статику по пути `/wiki/`. Клиент (мод F2 и сайт) грузит контент по цепочке: РФ-релей → Финляндия → бандл-фолбэк в jar мода (офлайн).

Правки контента появляются **без пересборки мода** — push в этот репозиторий → хосты обновляются.

## Спецссылки в статьях

- `[текст](vlp:market)` — кнопка-переход в раздел F2 (в игре реально открывает раздел).
- `[текст](wiki:bank/cards)` — переход к другой статье вики.
- Медиа: `<video src="assets/имя.webm" autoplay loop muted playsinline></video>`.

## Добавить статью

1. Создать `<категория>/<slug>.md`.
2. Добавить запись в `manifest.json` (в нужную категорию, на нужное место по порядку).
3. Push. Хосты подтянут автоматически.

Движок вики (рендер, навигация) — в репозитории web-ui (файлы `js/wiki.js`, `css/wiki.css`), не здесь.
