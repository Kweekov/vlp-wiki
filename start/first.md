# Первые шаги

Добро пожаловать на VLP! Здесь ванильный Minecraft «плюс» — без диких плагинов, но с удобными фичами вроде банка, маркета и своего мини-меню. Эта страница поможет быстро освоиться.

## 1. Попади в whitelist

Сервер приватный и работает по whitelist. Чтобы попасть на сервер, нужна заявка (и/или согласованное время добавления в whitelist). Пока тебя нет в whitelist — зайти не получится, даже если ник и пароль верны.

## 2. Авторизация

VLP использует свою систему авторизации — заходишь по «пиратке», но с логином и паролем:

- **Первый вход** — сервер попросит **зарегистрировать пароль**. Придумай надёжный пароль и не теряй его.
- **Каждый следующий вход** — попросит этот пароль ввести заново.

Если забыл пароль или есть проблемы со входом — обратись к администрации.

## 3. Хаб → игровой сервер

После авторизации ты попадаешь в **хаб** — это лобби сети. Из хаба нужно перейти на игровой сервер (выживание/фермы), чтобы начать играть: строительство, фермы, экономика.

## 4. Открой F2 — своё меню

На VLP есть встроенное меню, которое открывается клавишей **F2**. Внутри:

- твой **профиль** — статистика, настройки;
- **банк** — счета, переводы, карты (см. [Банк](wiki:bank/accounts));
- **маркет** — покупка/продажа между игроками (см. [Маркет](wiki:market/basics)).

Быстрый переход прямо сейчас: [Открыть профиль](vlp:profile).

## 5. Голосовой чат

На сервере работает голосовой чат через мод **Plasmo Voice** — он уже встроен в сборку. Как его настроить и пользоваться — смотри [Голос](wiki:voice/setup).
