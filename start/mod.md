# Клиент-мод VLP-Mod — установка и решение проблем

Для игры на VLP **обязателен клиент-мод VLP-Mod**: он рисует меню (F2), проходит авторизацию и связывает вас с сервером. Без правильно установленного мода сервер **не пустит** — покажет «Для игры нужен клиент-мод VLP-Mod». Ниже — что нужно поставить и как решить типичные проблемы.

## Что нужно поставить (точные версии)

Сервер работает на конкретной версии Minecraft, и мод собран **строго под неё**. Версии должны совпадать — иначе мод не загрузится.

| Компонент | Версия |
|---|---|
| **Minecraft** | **26.2** (снапшот — **НЕ** 1.21.4 и не другие!) |
| **Fabric Loader** | **0.19.3** или новее |
| **Fabric API** | **0.152.2+26.2** |
| **MCEF-Modern** | **0.3.3+mc26.2.jcef146.0.10** |
| **VLP-Mod** (vlpmenu) | последней версии (обновляется сам) |

> Проще всего использовать **готовый профиль** сборки под 26.2 со всеми этими модами (Modrinth App и т.п.) — тогда ничего не нужно собирать вручную. За готовой сборкой обратитесь к администрации.

## ❌ «Для игры нужен клиент-мод VLP-Mod» (кик при входе)

Этот кик означает: сервер **не получил ответ от мода** — то есть мод **не загрузился** у вас в игре. Мод при этом может лежать в папке, но не работать. Причины по частоте:

1. **Неправильная версия Minecraft или Fabric Loader (самая частая!).** Мод под **MC 26.2** и **Fabric Loader ≥ 0.19.3**. Если вы запускаете старую версию (например, 1.21.4) или старый лоадер (0.16.x) — Fabric **отказывается грузить мод**.
   - Как проверить: откройте `.minecraft/logs/latest.log` и поищите строки вида:
     ```
     HARD_DEP_NO_CANDIDATE vlpmenu ...
     Mod 'VLP-Mod' (vlpmenu) requires Minecraft 26.2.x, but only the wrong version is present: 1.21.4!
     Mod 'VLP-Mod' (vlpmenu) requires Fabric Loader >=0.19.3, but only the wrong version is present: 0.16.14!
     ```
     Если такие строки есть — у вас **не та версия игры/лоадера**. Поставьте версии из таблицы выше.
2. **Нет Fabric API или MCEF-Modern** нужной версии рядом с модом — поставьте их.
3. **Мод не в той папке** — jar должен лежать в `mods/` **того профиля**, которым вы заходите.
4. **Битый/старый jar мода** — удалите и поставьте свежий.

> VPN на это **не влияет**: кик за мод — это несовместимость версий, а не сеть.

## 🌐 Меню/страница входа не грузится, «404», чёрный экран

Интерфейс (авторизация, F2) грузится по сети, и в России **DPS/провайдер может её резать** — отсюда «404» или пустой экран.

- **Решение:** обновите мод до **последней версии** — в ней загрузка интерфейса и авто-обновление идут через наш релей и **устойчивы к блокировкам** (VPN больше не нужен).
- **Временно**, пока не обновились: включите VPN, либо добавьте `vimeline.online` в обход (zapret: `lists/list-general`). После обновления мода это не понадобится.

## 🖥️ F2 не открывается / краш при первом запуске

При первом нажатии F2 мод докачивает движок браузера (~150 МБ Chromium). Это отдельная тема — все способы (готовый пак, ожидание, VPN, сброс) описаны здесь:

- [F2 не открывается — решения](wiki:f2/troubleshooting)

---

## 🔄 Мод не обновляется

Последняя версия тянется автоматически через релей. Если обновление «зависло» — включите VPN на один запуск, либо переустановите свежий jar вручную (за ссылкой — к администрации).

---

## ✅ Как убедиться, что мод загрузился

В `.minecraft/logs/latest.log`:
- должны быть строки о загрузке `vlpmenu` / VLP-Mod **без** ошибок;
- **не должно** быть `HARD_DEP`, `requires ... wrong version`, `NoClassDefFound`, краша на старте.

Если мод загрузился корректно — при входе появится экран авторизации, а по F2 откроется меню.
